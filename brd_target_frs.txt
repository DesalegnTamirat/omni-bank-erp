FR-KMS-014: Role-Based Download Permission System shall only allow a document to be downloaded if the employee's assigned role has been granted download permission for that document; employees without permission can still view it on screen but cannot download it.

FR-KMS-015: Automatic Watermarking System shall automatically stamp every downloaded document with the downloader's user ID, the date and time of download, and their department, visible on the document itself. Purpose: if a copy is later found outside the system, it can be traced back to the person who downloaded it.

FR-KMS-016: Download Encryption System shall automatically lock (encrypt) every downloaded file so that only the authorized recipient can open it. If the file is later copied to another device, lost, or intercepted, its contents remain unreadable to anyone else. Purpose: protects what is inside the file itself, separate from the watermark, which only identifies who downloaded it.

FR-KMS-017: Download Audit Logging System shall automatically record, for every download, who downloaded which document and when, in a log that administrators and auditors can review. Purpose: provides a complete download history for compliance checks and investigations.

FR-KMS-018: View-Only Restriction System shall allow especially sensitive documents to be marked as view -only, which lets employees read the document on screen but removes the download option for that document entirely. Note on FR -KMS-015 (Download Encryption): encryption here does not require the intended user to enter a password or key. Decryption is intended to happen automatically for the authorized user, tied to their verified identity or active session (e.g., opened through the KMS's own viewer, or on a company-managed device), so it is invisible to someone with proper access. If the file ends up with anyone else, for example through loss, theft, or forwarding, it simply fails to open, since their identity or device does not match.
